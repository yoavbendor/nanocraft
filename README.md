# nanocraft

Realtime packet crafting on [nanom](https://github.com/yoavbendor/nanom) and [nanowire](https://github.com/yoavbendor/nanowire): compiled frame templates (patch in place, incremental checksums), IP and SOME/IP-TP segmentation, pcap/pcapng writers, AF_PACKET TX ring / sendmmsg / SO_TXTIME pacing, replay and fault injection.

Work in progress.
